# Experience logos

These SVGs preserve vector artwork so the small experience badges stay sharp on high-density displays and at browser zoom.

- `deriv.svg`: [Deriv's bot repository](https://github.com/deriv-com/bot/blob/master/public/deriv-logo.svg). Added the matching viewBox for scaling.
- `impiger.svg`: symbol paths from [Impiger's official logo](https://www.impigertech.com/wp-content/uploads/2025/07/Impiger_Logo-2.svg), framed without the wordmark to fit the badge.
- `bits-pilani.svg`: [BITS Pilani crest vector](https://en.wikipedia.org/wiki/File:BITS_Pilani-Logo.svg). Original paths and colours retained.

The surrounding text supplies the organization name, so the images use empty alt text to avoid repeating it to screen readers.
